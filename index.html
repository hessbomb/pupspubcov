What this model does not know

  • Rent is assumed, not quoted. Budget flags use $11/SF gross against an $11,000/month target. No Covington lease comps exist publicly — every figure needs broker confirmation.
  • Crime is partly estimated. Five of fourteen neighbourhoods carry a NeighborhoodScout-sourced ranking; the rest are judgment calls, flagged in the workbook.
  • Zoning is not scored. Covington's Neighborhood Development Code review sits outside this model, as does the Kentucky food-code rule limiting dogs to outdoor areas.
  • Building size is mixed-source. LoopNet gross area where available; elsewhere a single-storey footprint derived from GIS geometry, which understates multi-storey buildings.
  • Flood sub-bands are an owner decision. FEMA NFHL zones were joined 2 August 2026 for all 328 parcels (objective). The point split — X 5, shaded X 4, levee-protected X 3.5, AE 0 — is an owner-approved weighting choice, not a FEMA designation.
  • Multipliers are factor-scoped as of model v8 (owner decision, 2 Aug 2026). Score = BldgFit×avail×lot + Convertibility×zoning×avail×lot + Yard×lot + Location×zoning×avail + Crime + Flood + Environmental. Crime, flood, and environmental points are immune to all multipliers, so scores run ~7 pts higher than v7 — compare ranks, not raw scores, across versions. Factor bars in the detail panel show post-multiplier contributions.
  • Zoning discounts Location and Convertibility only (owner decision, 2 Aug 2026). NDC Table 03.06.3 was verified against the official code: a graduated multiplier (permitted 1.0 · SU corner-unverified 0.9 · conditional-path 0.7 · prohibited-with-alt-path 0.5 · no-path 0.3) applies to those two factors and nothing else. District status is objective code data; the tier values are an owner-approved judgment. SU parcels await a corner-lot check; dog-bar use classification remains an Administrator determination.
